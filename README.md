# EventFlow CRM — prototype Streamlit

Prototype de démonstration d'un CRM pour petites agences événementielles.

## Lancer l'application
1. Installer Python 3.10 ou supérieur.
2. Ouvrir un terminal dans ce dossier.
3. Installer : `pip install -r requirements.txt`
4. Lancer : `streamlit run app.py`

La base SQLite `eventflow.db` est créée automatiquement au premier lancement et pré-remplie avec des données fictives.
